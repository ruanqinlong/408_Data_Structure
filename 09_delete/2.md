# 彩带问题：递推关系推导

## 一、题目描述

有白色（W）、红色（R）、蓝色（B）三种彩带，要求：

1. 相邻彩带颜色不能相同。
2. 每条蓝色彩带必须夹在一条白色彩带和一条红色彩带之间。

求长度为 n 的合法彩带排列方案数。

## 二、关键分析

蓝色彩带只能出现在以下组合中：

- WBR
- RBW

蓝色不能位于序列首尾。

定义：

f(n) = 长度为 n 的合法排列方案数。

因为序列末尾只能是白色或红色，所以可以根据最后两条彩带进行分类。

## 三、递推推导

### 情况一：倒数第二条不是蓝色

由于最后一条不能是蓝色，且相邻不能同色，最后两条只能为：

- WR
- RW

任意长度为 n-1 的合法序列，末尾必为 W 或 R。

在其后面添加另一种颜色，必然得到唯一的长度为 n 的合法序列。

因此，本情况的方案数为：

$$
f(n-1)
$$

### 情况二：倒数第二条是蓝色

由于蓝色必须位于白色和红色之间，末尾三条只能为：

- WBR
- RBW

任意长度为 n-2 的合法序列，末尾必为 W 或 R。

若末尾是 W，添加 BR；
若末尾是 R，添加 BW。

每种长度为 n-2 的合法序列，都能唯一扩展为一种长度为 n 的合法序列。

因此，本情况的方案数为：

$$
f(n-2)
$$

### 合并两种情况

两种情况互不重叠，且覆盖全部合法排列，因此：

$$
\boxed{f(n)=f(n-1)+f(n-2)}
$$

适用于 n≥3。

## 四、初始条件

当 n=1 时：

W、R，共 2 种。

$$
f(1)=2
$$

当 n=2 时：

WR、RW，共 2 种。

$$
f(2)=2
$$

当 n=3 时：

WRW、RWR、WBR、RBW，共 4 种。

$$
f(3)=f(2)+f(1)=4
$$

## 五、最终递推公式

$$
\boxed{
f(n)=
\begin{cases}
2, & n=1 \\
2, & n=2 \\
f(n-1)+f(n-2), & n\ge 3
\end{cases}
}
$$

## 六、算法实现（C++）

```cpp
#include <iostream>
using namespace std;

long long ribbon(int n) {
    if (n <= 0) return 0;
    if (n <= 2) return 2;

    long long a = 2, b = 2;

    for (int i = 3; i <= n; i++) {
        long long c = a + b;
        a = b;
        b = c;
    }

    return b;
}

int main() {
    int n;
    cin >> n;
    cout << ribbon(n) << endl;
    return 0;
}
```

时间复杂度：O(n)

空间复杂度：O(1)

注：long long 仍可能在 n 较大时溢出。

## 七、解题方法总结

本题采用动态规划思想。

核心步骤：

1. 定义状态 f(n)，表示长度为 n 的合法方案数。
2. 分析序列末尾的结构，确定分类标准。
3. 将所有合法方案划分为互不重复的情况。
4. 分别建立与较小规模问题的对应关系。
5. 将各类方案数相加，得到递推式。
6. 确定初始条件。

**最重要的思想：递推式不能只靠观察数字猜测，而应证明每一种情况都能与较小规模的问题形成一一对应，并确保分类不重不漏。**

最终结论：

$$
\boxed{f(n)=f(n-1)+f(n-2)}
$$
