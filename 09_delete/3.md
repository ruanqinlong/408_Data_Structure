# 跳过一个城市——最短路径问题

## 一、题目核心

有 n 个城市，按照 1 到 n 的顺序经过，允许跳过一个中间城市，使总距离最短。

城市 i 和城市 j 之间的曼哈顿距离：

\[
d(i,j)=|x_i-x_j|+|y_i-y_j|
\]

## 二、解题思路

采用枚举法，不需要使用动态规划或递推。

核心思想：

1. 计算不跳过任何城市时的总距离。
2. 枚举每一个允许跳过的城市。
3. 计算跳过该城市能够节省的距离。
4. 找出最大节省距离。
5. 用原始总距离减去最大节省距离。

## 三、原始总距离

不跳过城市时，路线为：

\[
1\rightarrow2\rightarrow3\rightarrow\cdots\rightarrow n
\]

总距离：

\[
\boxed{
S=\sum_{i=1}^{n-1}d(i,i+1)
}
\]

## 四、推导核心公式

假设跳过第 i 个城市。

原来的局部路线：

\[
(i-1)\rightarrow i\rightarrow(i+1)
\]

原来的局部距离：

\[
d(i-1,i)+d(i,i+1)
\]

跳过城市 i 后，路线变为：

\[
(i-1)\rightarrow(i+1)
\]

新的局部距离：

\[
d(i-1,i+1)
\]

因此，跳过城市 i 节省的距离为：

\[
\boxed{
\Delta_i=
d(i-1,i)+d(i,i+1)-d(i-1,i+1)
}
\]

注意：跳过一个城市，只会改变与该城市相邻的两段路线，其他路线均不变。

## 五、最终答案

为了使总距离最短，需要让节省的距离最大。

因此：

\[
\boxed{
Ans=S-\max_{2\leq i\leq n-1}\Delta_i
}
\]

也就是：

\[
\boxed{
Ans=S-\max_{2\leq i\leq n-1}
\left[
d(i-1,i)+d(i,i+1)-d(i-1,i+1)
\right]
}
\]

## 六、C++ 实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cstdlib>
using namespace std;

struct Point {
    int x, y;
};

int distance(Point a, Point b) {
    return abs(a.x - b.x) + abs(a.y - b.y);
}

int main() {
    int n;
    cin >> n;

    vector<Point> p(n);

    for (int i = 0; i < n; i++) {
        cin >> p[i].x >> p[i].y;
    }

    long long sum = 0;

    // 计算原始总距离
    for (int i = 0; i < n - 1; i++) {
        sum += distance(p[i], p[i + 1]);
    }

    long long maxSave = 0;

    // 枚举可以跳过的城市
    for (int i = 1; i < n - 1; i++) {
        long long save =
            distance(p[i - 1], p[i])
            + distance(p[i], p[i + 1])
            - distance(p[i - 1], p[i + 1]);

        maxSave = max(maxSave, save);
    }

    cout << sum - maxSave << endl;

    return 0;
}
```

## 七、复杂度分析

- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(n)\)

原因：

- 读取城市坐标需要 \(O(n)\)。
- 计算原始总距离需要 \(O(n)\)。
- 枚举所有可以跳过的城市需要 \(O(n)\)。
- 使用数组保存 n 个城市坐标，需要 \(O(n)\) 空间。

## 八、解题思想总结

本题的核心不是重新计算每一种跳过方案的完整路线，而是观察跳过一个城市后，究竟有哪些部分发生了变化。

原路线：

\[
A\rightarrow B\rightarrow C
\]

跳过 B：

\[
A\rightarrow C
\]

只需要计算：

\[
d(A,B)+d(B,C)-d(A,C)
\]

就能知道跳过 B 节省了多少距离。

**重要思想：当一个操作只会影响整体结构中的局部部分时，可以先计算整体原始结果，再计算局部变化量，最终通过增量或减量得到答案。**

这种方法能够将枚举每种方案并重新计算总距离的 \(O(n^2)\) 做法，优化为 \(O(n)\)。

这是本题最值得掌握的优化思想。
